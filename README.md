
# AI Ping Pong Game with Fuzzy Logic

This project is an AI-driven Ping Pong game that utilizes fuzzy logic to enhance gameplay. The AI uses fuzzy logic to make dynamic decisions, creating a more challenging and engaging experience for players.

## Features

- **AI Opponent**: The game features an AI opponent that adapts using fuzzy logic to decide paddle movements.
- **Sound Effects**: Enjoy sound effects that provide feedback for paddle hits and scoring.
- **Gameplay Recording**: Includes a sample gameplay video (`gameplay.mp4`) to showcase the functionality.

## Prerequisites

- Python 3.x
- Libraries listed in `requirements.txt` (e.g., `pygame`)

## Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/webgeekhabib007/AI_ping_pong_game_with_Fuzzy_Logic.git
   ```

2. **Navigate to the project directory**:

   ```bash
   cd AI_ping_pong_game_with_Fuzzy_Logic
   ```

3. **Install dependencies**:

   Make sure you have Python installed. Then, install the required Python packages:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

To play the game, run the main script:

```bash
python main.py
```

## How It Works

- The **AI opponent** uses fuzzy logic to determine paddle movements based on the ball's position and velocity.
- The game is built using the `pygame` library to handle graphics, input, and sound effects.
